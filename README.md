## Learning Path

A practical progression through the collection is:

1. **Begin with information discovery** — Nagini Encoded Secrets and Nagini WWW-Data Enumeration.
2. **Practice web investigation** — Nagini Shell Hunt and Joomla Loot Hunter.
3. **Explore application security** — Nagini Admin Break-In and Nagini SQL Reset.
4. **Learn Joomla reconnaissance** — Joomla Joomscan Recon.
5. **Study SSRF concepts** — Nagini Gopher SSRF.
6. **Practice Gopher concepts** — Gopher Payload Forge.
7. **Connect SSRF with internal services** — Nagini SSRF MySQL Tunnels.
8. **Finish with backup-focused investigation** — Backup Box Breach.

## How to Use the Labs

Use these CTF and cybersecurity labs only against systems and environments where you have explicit authorization.

Recommended workflow:

1. Read the lab objectives and requirements.
2. Identify the available attack surface and information.
3. Perform reconnaissance systematically.
4. Record discovered services, paths, technologies, and observations.
5. Study the relevant security concept before testing it.
6. Perform activities only within the authorized lab environment.
7. Document your methodology and lessons learned.
